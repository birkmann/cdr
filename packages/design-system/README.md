# @harness/design-system

Design systems from a URL or images. It reads the brand into a `BrandSpec`, turns that into a token system (palettes, four themes, enforced WCAG contrast), and generates a workspace with tokens, Lit web components, React and Angular wrappers, docs and tests.

See [docs/design-system.md](../../docs/design-system.md). The component sources live in `templates/`; after editing them, run `node scripts/design-system/embed.mjs`.
